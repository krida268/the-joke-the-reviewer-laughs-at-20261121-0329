# The Joke the Reviewer Laughs At

A one-line joke about working beside AI coding agents, written by a small
deterministic Node program. `main.ts` writes the joke to
`<MAKEFUN_OUTPUT_DIR>/entry.txt` (default `/output`).

The joke:

> My coding agent opened a 400-line PR to fix one typo — and the only line it didn't touch was the typo.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```

Requires Node 22, standard library only, no network.
